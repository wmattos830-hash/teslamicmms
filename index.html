👥 Usuários

Gerencie usuários diretamente no painel do Supabase (Authentication → Users). Os perfis (admin/técnico/visualizador) são definidos na tabela profiles.

🔒 Permissões

As permissões são controladas pelo RLS do Supabase com base no campo role da tabela profiles:

  • admin — acesso total (criar, editar, excluir)
  • tecnico — criar e editar, sem excluir
  • visualizador — apenas leitura

Para alterar o perfil de um usuário, edite a coluna role dele em Table Editor → profiles no Supabase.
